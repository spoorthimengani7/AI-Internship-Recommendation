# 🤖 AI Internship Recommendation System

## 📌 Project Overview

The **AI Internship Recommendation System** is a Python-based application that helps students find suitable internships based on their skills, interests, and preferences.

The system analyzes the student's input and recommends relevant internship opportunities. It is designed to make the internship search process easier, faster, and more personalized.

## 🎯 Objectives

- Help students find suitable internships.
- Recommend internships based on skills and interests.
- Reduce the time required to search for internships.
- Provide personalized internship recommendations.
- Create a simple and user-friendly interface.

## ✨ Features

- 🔍 Internship search and recommendation
- 🤖 AI-based recommendation
- 📋 Internship details
- 🎓 Skill-based recommendations
- 📊 Internship dataset using CSV
- 🖥️ Simple and easy-to-use interface

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Pandas**
- **Ollama / AI Model**
- **CSV Dataset**
